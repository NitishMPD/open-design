### 🌟 Codename: *Go Time*

🧭 **28 个 PR · 10 位贡献者 · 2 天** — **全新入门档 Go 正式上线，官网定价页与应用
内升级入口一起打通。套餐内模型在余额为零时照常可用，图片生成失败会告诉你原因，从
Home 发起的第一个任务全程保持实时输出。** 0.20.0 让你做出来的东西立得住，
0.20.1 则是把挡在它们前面的那些小台阶一个个搬掉。

## 🔥 亮点

- 🟢 **Go 来了——一个真正适合起步的套餐。** 新的入门档一次做完整条链路：官网定价
  页多了 Go 这一档，首页挂上上线 banner，应用内的升级入口也直接跳到 Pricing，
  而不是停在一个走不下去的弹窗。套餐名称、排序和文案在应用和官网上终于是同一套。
  (#7121, #7122, #7167)

- 🔋 **余额为零不再把你挡在自己付过费的模型外面。** 如果你的套餐本身包含某个模型
  的不限量使用，那么即使钱包显示 0，模型选择器也照常提供它——余额和权益是两件事，
  只有其中一件该决定模型列表。 (#7187)

- 🖼️ **图片没生成出来时，你能知道为什么。** 过去所有失败都会收敛成同一句笼统提示。
  现在真正的原因会传到你面前——是安全策略拒绝、供应商报错，还是 prompt 有问题——
  你才知道该重试、换个说法，还是换个模型。 (#7118)

- 💬 **在 Home 提的第一个需求，会一路流式跑完。** 从 Home 发起任务时，输出可能中途
  停住不动，而后台其实还在跑。现在第一个任务从第一个 token 到最后一个都保持实时。
  (#7071)

- ⏱️ **「这个跑了多久」终于是它字面的意思。** 运行耗时现在以模型真正开始响应的那一
  刻为起点，排队和启动时间不会再被算进生成时长里。 (#7155)

- 🧩 **Handoff to OpenCode。** 一个新的社区插件，可以把当前这份活儿交接给
  OpenCode，让在 Open Design 里开的头，在你更习惯的 agent 里继续。 (#6948)
  感谢 @ross-sec。

- 🏷️ **一个名字，处处一致：OpenDesign。** 产品名、导航和 CTA 在应用与官网上统一，
  不再在两种写法之间摇摆。 (#6983, #6998) 感谢 @joeylee12629-star。

- ⚡ **打开会话列表不再做多余的事。** 列表不会再为了画出自己而把完整事件日志展开，
  这在历史很长的项目上直接体现为面板更快。 (#6978) 感谢 @jiulongche。

## 🩹 修复

- 「关于」面板里更新那一行的间距恢复正常，打开项目时画框也不会再闪两次。 (#7174)
- 部署失败会返回具体错误码，而不是一个笼统的 400，失败时能看清到底哪里出了问题。
  (#5897)
- 删除一个技能后，它会从 `@` 提及选择器里一并清掉，不再留下一条失效条目。 (#6920)
  感谢 @T-sanjay-ram。
- 重新接回正在运行的会话时，回放事件会合并处理，而不是一条条重放。 (#6926)
  感谢 @roian6。
- `PATHEXT` 配置异常的 Windows 机器上，agent 运行时也能正常启动。 (#6937)
  感谢 @github-lover-9999。
- `od media wait` 和 `od media generate` 会在退出前把输出刷干净，管道和脚本调用
  不再丢掉最后几行。 (#6800) 感谢 @lorenzozanee。
- 作品的升级引导只对云端模型出现，不会再打扰自带模型的用户。 (#6995)
- 预览的字体样式表改为延迟加载，不再阻塞预览本身。 (#7134)
- DeepSeek Harness 的 bootstrap 版本改为从安装包字节推导，显示的版本与实际装上的
  一致。 (#7107)
